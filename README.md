# sanstypo-site

The website for SansTypo: what it is, where to download it, and the privacy
policy the browser stores require at a public URL.

Plain HTML and one stylesheet, served by GitHub Pages from `main`. No build
step: edit the files, push, and the site updates.

- `index.html` — the product page and the download links
- `privacy.html` — the privacy policy for the browser extension
- `style.css` — the whole design

The application itself lives in a separate, private repository. Downloads are
attached to this repository's releases.
